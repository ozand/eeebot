
## Repository scripts

The source paths below map to behavioral contracts, limits, and verified existing assertions. This documentation task does not execute scripts.

- Operator-safe text consolidation [[scripts/agents_md_consolidate.py#plan_removal]] only removes explicitly selected uniquely named, marked-droppable sections; dry-run is default and writes are atomic. [[tests/test_agents_md_consolidate.py#test_refuses_a_critical_unmarked_section_and_writes_nothing]] verifies all-or-nothing refusal; [[tests/test_agents_md_consolidate.py#test_apply_preserves_a_symlink_and_updates_its_target]] verifies the symlink boundary. This is operator-only, not loop-reachable.
- Deterministic change reporting [[scripts/change_shape.py#classify_subject]] classifies commit subjects without model calls; [[scripts/change_shape.py#distribution_from_rows]] counts successful outcome rows within a time window and leaves missing/legacy classes explicitly unclassified. [[tests/test_change_shape.py#test_classify_subjects_is_deterministic_and_model_free]] and [[tests/test_change_shape.py#test_distribution_from_rows_is_windowed_and_legacy_safe]] verify these limits.
- Queue cleanup [[scripts/cleanup_subagent_queue.py#main]] combines age-based archival, max-queue trimming, metadata exclusions, and archive retention; dry-run prevents moves/pruning but still reports intended actions. [[tests/test_cleanup_subagent_queue.py#test_metadata_files_excluded_from_queue_and_archival]], [[tests/test_cleanup_subagent_queue.py#test_max_queue_count_based_archival]], and [[tests/test_cleanup_subagent_queue.py#test_archive_pruning_30_days]] cover distinct constraints.
- Lesson compilation [[scripts/compile_project_lessons.py#main]] folds goal-history PASS/BLOCK records into deduplicated lesson/error data while filtering state artifacts and retaining handwritten errors; [[tests/test_compile_project_lessons.py#test_main_compiles_pass_and_block_cycles]] and [[tests/test_compile_project_lessons.py#test_main_preserves_handwritten_errors_and_keeps_them_first]] verify. Unlike memory archive and story tools, it is a separate history-to-YAML compiler.
- History curation [[scripts/cycle_logger.py#append_cycle_summary]] prepends one nonduplicate cycle entry; dedup/compaction/statistics are explicit separate operations. [[tests/test_cycle_logger.py#test_dedup_dry_run_does_not_write]] verifies dry-run preservation. [[scripts/memory_archiver.py#archive]] partitions recent and older history and uses deterministic summary fallback when LLM summary is unavailable; [[tests/test_memory_archiver.py#test_undated_line_is_stamped_with_todays_date_not_dropped_or_rejected]] confirms its undated-entry policy. Story synthesis [[scripts/journal_story.py#load_day_journal]] and publication-intake validation are separate stages; intake accepts only local producer artifacts, validates narration and citation coverage, and returns a constrained manifest via [[scripts/publication_intake.py#validate_story_artifact]]. [[tests/test_publication_intake.py#test_intake_rejects_external_or_tampered_payload]] and [[tests/test_publication_intake.py#test_intake_rejects_missing_citation_set]] test trust boundary. [[scripts/migrate_backlog_title.py]], [[scripts/migrate_evolution_tree.py]] are one-time state migrations; direct test-symbol coverage for these two paths was not established.
- Runtime/host cost probes [[scripts/cycle_cost_probe.py#battery_probe]] preserve `present`/`absent`/`unanswerable` rather than collapsing missing sensor evidence; [[scripts/cycle_cost_probe.py#full_surface_push_cost]] accepts an injected writer and does not open the device itself. [[tests/test_cycle_cost_probe.py#test_battery_probe_distinguishes_presence_absence_and_unanswerable]] and [[tests/test_cycle_cost_probe.py#test_full_surface_push_reports_microseconds_and_exact_payload_size]] verify the distinction. [[scripts/probe_host_capabilities.py#refresh_host_capabilities]] records triggered host observations with explicit unavailable states; [[tests/test_host_capabilities_unit.py#test_probe_output_matches_independent_golden_baseline]] verifies stable output contract. [[scripts/probe_demo_budget.py#main]] is a demo-budget measurement, while [[scripts/shape_cost_report.py#build_shape_report]] analyzes recorded shape/cost data; direct tests for these specific entrypoints are unknown.
- Tile artifact codec [[scripts/tile_frame_encoder.py#encode_frames]] writes versioned, chunked keyframes/deltas; [[scripts/tile_frame_encoder.py#decode_artifact]] rejects malformed/version-mismatched payloads. [[tests/test_tile_frame_encoder.py#test_round_trip_preserves_synthetic_tile_sequence]] and [[tests/test_tile_frame_encoder.py#test_unknown_artifact_version_fails_loudly]] cover round-trip and version boundary.
- Cycle metrics [[scripts/loop_metrics_report.py#compute_metrics]] groups phase rows by cycle and reports terminal, duplicate, gate, and success rates; incomplete cycles remain distinct. [[tests/test_loop_metrics_report.py#test_failed_call_stream_does_not_change_l1_token_budget]] asserts failed-call artifacts do not contaminate the L1 token count. [[scripts/llm_calls_report.py#aggregate]] summarizes recorded call telemetry, while [[scripts/llm_prompt_inspect.py#summarize_call]] provides bounded prompt-call inspection; no direct symbol-level test evidence for prompt inspection was found.
- Artifact verification [[scripts/verify_materialized_improvement.py#validate_artifact]] and [[scripts/verify_release_health.py#validate_health_and_metrics]] validate materialized improvement and release-health contracts; direct tests for these two scripts were not found. [[scripts/measure_package_1903.py#build_cycle_records]] reconstructs package-cycle records, with [[tests/test_measure_package_1903.py#test_window_selection_and_per_cycle_fields]] as evidence; [[scripts/export_package_1903_base_fixture.py#before_window]] only exports pre-window fixture data. These reporting/verification utilities consume evidence but do not establish fitness authority; see [[evidence]].
- Bridge wrapper [[scripts/eeepc_self_evolving_subagent_bridge.py]] only delegates to the runtime bridge entrypoint; [[tests/test_bridge_wrapper.py]] covers the wrapper/import boundary. Local CI [[scripts/run_local_ci.py#main]] delegates to [[nanobot/runtime/local_ci.py#run_and_record_local_ci]]: it refuses to invoke pytest if any selected target is missing and records `targets_missing` distinctly from a red run; [[tests/test_local_ci.py#test_absent_targets_are_not_reported_as_a_red_suite]] and [[tests/test_local_ci.py#test_a_suite_that_actually_ran_is_labelled_ran]] verify that distinction. Default targets remain a bounded harness subset, not the full suite.
- Replay and recovery tools serve separate contracts: [[scripts/replay_semantic_dedup.py#audit_coverage]] audits replay coverage, and [[tests/test_replay_semantic_dedup.py]] provides related test coverage; [[scripts/revert_cycles.py#resolve_targets]] selects eligible cycle reverts and [[tests/test_revert_cycles.py]] covers revert selection/refusal. Planner/bridge host scripts [[scripts/smoke_test_loop.py]], [[scripts/run_persona_harness.py#main]], [[scripts/run_stability_3runs.py]], [[scripts/loop_explorer_cli.py#main]], and [[scripts/prototype_already_implemented.py#run_replay]] have test files [[tests/test_persona_harness.py]] only for persona-harness entry; direct test-symbol evidence for smoke, stability, explorer, and prototype remains unknown. Their intended runtime boundaries are [[architecture#Two runtime surfaces#Bounded self-evolving bridge|bounded bridge]], [[gates-and-promotion]], and [[docs/specs/subagent-bridge/spec.md]].
- Telegram proof validator [[scripts/validate_telegram_live_proof.py#evaluate_telegram_live_proof_markdown]] rejects missing real allowlisted transcripts and simulated/local evidence; [[tests/test_telegram_live_proof_validator.py#test_simulated_or_local_artifact_is_invalid_even_with_success_words]] checks this trust boundary. Its collector [[scripts/collect_telegram_live_proof.py#collect_telegram_live_proof_markdown]] emits redacted metadata only for valid evidence; [[tests/test_telegram_live_proof_collector.py#test_collector_redacts_secret_like_reply_and_metadata]] checks redaction. Neither performs network access. Daily movement [[scripts/judge_daily_movement.py#evaluate_daily_movement]] distinguishes progressive code delivery from metadata-only appearance and preserves unattributed killed runs as incomplete; [[tests/test_judge_daily_movement.py#test_killed_runs_count_as_attempts_and_wasted_box_and_unattributed_is_incomplete]] verifies. Dashboard [[scripts/eeebot_dashboard.py#collect_metrics_uncached]] renders state-derived operator visibility, not a gate; [[tests/test_eeebot_dashboard_truth.py]] exercises dashboard truth labels. No live proof or dashboard execution is claimed.
- Privileged preflight [[scripts/eeepc_privileged_rollout_preflight.py#build_preflight]] reports access/readiness checks without performing rollout; [[tests/test_eeepc_privileged_rollout_preflight.py]] exercises command construction/guard outcomes. Contract [[docs/specs/host-runtime/spec.md]]; code presence does not authorize host access.
