# Design

## Roots and precedence

`nanobot/skills/` is the release-owned root. Instance `skills/` remains loop-owned. `SkillsLoader` enumerates release skills before workspace skills, skips a workspace name that collides with a release name, and preserves existing builtin behaviour for all other package skills.

## Read boundary

Restricted loop and subagent read tools admit `BUILTIN_SKILLS_DIR`, which is the package root. Writes remain restricted to the workspace. The skill-read callback must recognize both roots so read telemetry remains meaningful.

## Index and migration

`skills/index.md` remains in the instance repository and is generated by the existing `render_skills_index()` path. It renders source labels. The product PR adds release copies first; a separately verified instance-repository cleanup commit removes the old three copies only after deployment proves reads.

## Enforcement

The release tree is absent from the instance Git commit surface. The gate test models a release-root path and requires rejection rather than depending only on POSIX ownership. No new mutable path is introduced.

## Rollback

Revert the product PR to return loader precedence and package content. Because instance copies remain during this increment, the pre-migration instance path remains available. Cleanup is intentionally deferred.
