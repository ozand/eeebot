# USER.md: how to retire a directive (#1722)

A directive in `USER.md` is never deleted. When the operator changes a
preference, rewrite the active directive in place under **Directives** so the
list carries one current answer per question, and move the old sentence
unchanged to **Superseded** with two additions: the date it was retired and
the directive that replaced it (quote it or name it). Never append a second,
contradictory active directive next to the old one — a reader of the active
list must not have to arbitrate. If a directive is withdrawn with no
replacement, its Superseded entry says "withdrawn" in place of the
replacement. The whole file stays under its 4 000-char budget including the
Superseded section; when the active list nears about fifteen entries, fold
overlapping directives into one before adding another, and record the fold
in Superseded the same way. The dates and source references on every line
are what make the history readable without a changelog; keep them.
